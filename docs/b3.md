# B3

Integração com dados da B3 utilizados pelo `cvmdata`.

## Tickers

Os tickers da B3 são necessários para o cálculo de alguns indicadores, principalmente os relacionados a **valuation**. Para esses cálculos, é necessário conhecer o ticker da empresa, seu tipo (ON ou PN) e a quantidade de ações emitidas.

O `cvmdata` possui como dependência o projeto [b3-tickers](https://github.com/dalmofelipe/b3-tickers), responsável por consultar automaticamente um endpoint da B3 e gerar arquivos `.json` contendo informações dos tickers negociados.

Antes da execução do `cvmdata`, o `b3-tickers` deve ser executado. Os arquivos gerados devem ser copiados pelo processo de CI/CD para o diretório:

```text
./cvmdata/data/b3_tickers
```

Durante a execução do pipeline, o `cvmdata` identifica automaticamente esse diretório e integra os dados dos tickers à base principal.

Caso o diretório `data/b3_tickers` não exista, essa etapa será ignorada. O pipeline continuará normalmente, porém alguns indicadores de valuation não poderão ser calculados.

## Quantidade total de ações emitidas

O pipeline do `cvmdata` integra os dados do documento **Composição do Capital Social**, disponibilizado pela CVM, contendo a quantidade de ações emitidas por cada companhia.

São importadas as quantidades de:

- Ações ordinárias (ON);
- Ações preferenciais (PN);
- Ações em circulação;
- Ações em tesouraria.

Esses dados são armazenados na tabela:

```text
composicao_capital
```

Essa informação é utilizada em conjunto com os dados dos tickers para o cálculo de indicadores por ação.

## Histórico de cotações

Para calcular indicadores de valuation, também é necessário conhecer o preço da ação correspondente à data de referência (`DT_REFER`) de cada demonstração financeira.

Para esse objetivo, o ecossistema do `cvmdata` possui outra dependência: [b3-cotahist](https://github.com/dalmofelipe/b3-cotahist)

O projeto `b3-cotahist` processa o arquivo histórico de negociações da B3 (`COTAHIST`) e produz uma base de dados estruturada contendo, entre outras informações:

| Coluna | Descrição |
| --- | --- |
| **data_pregao** | Data utilizada para relacionar a cotação à `DT_REFER` correspondente. |
| **ticker** | Código de negociação da ação (ex.: PETR3, PETR4). |
| **nome_empresa** | Nome da companhia, utilizado para validação dos dados. |
| **especificacao** | Especificação do ativo (ON, PN etc.), utilizada como validação adicional. |
| **preco_abertura** | Preço de abertura do pregão. |
| **preco_maximo** | Maior preço negociado no pregão. |
| **preco_minimo** | Menor preço negociado no pregão. |
| **preco_medio** | Preço médio negociado no pregão. |
| **preco_fechamento** | Preço de fechamento do pregão. |
| **oferta_compra** | Melhor oferta de compra registrada. |
| **oferta_venda** | Melhor oferta de venda registrada. |

Essa integração permitirá o cálculo de indicadores como:

- Market Cap;
- Valor Patrimonial por Ação (VPA);
- P/VPA;
- LPA;
- P/L;
- EV/EBIT;
- EV/EBITDA;
- Dividend Yield;
- entre outros indicadores dependentes do preço de mercado da ação.
